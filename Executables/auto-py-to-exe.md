# Auto-py-to-exe

Auto-py-to-exe **es una herramienta** de interfaz gráfica de usuario (GUI) **que convierte los scripts de Python (.py) en archivos ejecutables de Windows (.exe)**. Esta herramienta proporciona una interfaz sencilla para convertir scripts de Python en ejecutables a través de pyinstaller.

Un caso de ejemplo podría ser el siguiente:

Supongamos que tienes un script de Python llamado `my_script.py` que quieres distribuir a personas que no tienen Python instalado en sus computadoras. En lugar de pedirles que instalen Python y las dependencias necesarias, puedes usar auto-py-to-exe para convertir tu script en un archivo .exe que puede ser ejecutado en cualquier máquina con Windows.

Aquí están los pasos básicos que seguirías:

1. Instala auto-py-to-exe. Puedes hacer esto usando pip, el administrador de paquetes de Python, con el comando: `pip install auto-py-to-exe`

2. Una vez instalado, puedes iniciar la interfaz gráfica de usuario ejecutando `auto-py-to-exe` en tu línea de comandos.

3. En la interfaz gráfica de usuario, selecciona tu script de Python (`my_script.py`) como el script de entrada.

4. Ajusta las opciones según tus necesidades. Por ejemplo, puedes elegir si quieres que tu ejecutable sea de un solo archivo o de varios archivos, si quieres incluir iconos, etc.

5. Haz clic en el botón "Convertir .py a .exe".

6. Auto-py-to-exe creará un archivo .exe en la ubicación que hayas especificado. Ahora puedes distribuir este archivo .exe a cualquier persona que utilice Windows, y podrá ejecutar tu script de Python sin necesidad de instalar Python ni ninguna otra dependencia.
